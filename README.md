# 📋 Copy-Paste Helper

> A lightweight browser tool for copying and pasting text with the modern Clipboard API.

## ✨ Features
- Copy with `navigator.clipboard.writeText()`
- Paste with `navigator.clipboard.readText()`
- Live success/error feedback
- Responsive UI
- Fully client-side
